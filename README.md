# Трекер привычек и целей

Настольное приложение на **Python 3 + Tkinter + SQLite** для ежедневного контроля
привычек и долгосрочных целей. Интерфейс и логика написаны вручную кодом:
не используются Tilda, Wix, конструкторы приложений, low-code и no-code платформы.
Сторонние пакеты не нужны — только стандартная библиотека Python.

## Быстрый запуск

```bash
python main.py
```

Если `python` не находится, используйте `py main.py`. При первом запуске база
`data/habit_tracker.db` создаётся и заполняется тестовыми данными автоматически.

### Демо-доступы

| Логин | Пароль | Роль | Возможности |
|---|---|---|---|
| `admin` | `admin123` | администратор | всё, что может пользователь + панель администрирования (пользователи, справочники, добавление/изменение/удаление привычек и целей любого пользователя, журнал) |
| `user` | `user123` | пользователь | свои привычки, цели, прогресс, отчёты |

Пароли в базе не хранятся в открытом виде: `PBKDF2-HMAC-SHA256`, 210 000
итераций, индивидуальная соль, сравнение через `hmac.compare_digest`.

## Структура базы данных

```
roles ──< users ──< habits ──< habit_logs
                 └──< goals  ──< goal_progress
categories ──< habits, categories ──< goals
users ──< action_logs
```

| Таблица | Назначение |
|---|---|
| `roles` | роли: admin / user |
| `users` | логин, хэш пароля, соль, роль, ФИО |
| `categories` | справочник категорий с цветом |
| `habits` | привычки пользователя |
| `goals` | цели с целевым значением и дедлайном |
| `habit_logs` | ежедневные отметки выполнения (уникальность: привычка + дата) |
| `goal_progress` | история изменения прогресса цели |
| `action_logs` | журнал действий пользователей |

## Цветовая схема и шрифты (для защиты)

Палитра зафиксирована в `theme.py`:

* `#0F172A` — тёмный сланец, база шапки и бокового меню. Высокий контраст
  с белым текстом (более 14:1), выглядит строго и профессионально.
* `#F1F5F9` — светлый сланец, фон рабочей области. Это тот же оттенок, что
  и у шапки, но осветлённый: монохромная база без пестроты.
* `#FFFFFF` — белые карточки. Принцип 60/30/10: нейтральная база, поверхности,
  акценты.
* `#2563EB` — синий акцент действий. Синий ассоциируется с доверием и был выбран
  как единственный основной акцент, чтобы не перегружать интерфейс.
* `#10B981` — изумруд для успеха; `#F59E0B` — янтарь для предупреждений;
  `#EF4444` — красный только для удаления и ошибок. Акцент и успех соседствуют
  в цветовом круге (аналогичная гамма), поэтому не конфликтуют.

Шрифтовая пара:

* **Segoe UI** — основной интерфейсный шрифт: нейтральный гуманистический
  гротеск, крупный x-height, хорошо читается на экране, встроен в Windows.
* **Consolas** — моноширинный шрифт для чисел, дат, ID и логов: фиксированная
  ширина и табличные цифры выравнивают столбцы. Вместе они дают классический
  контраст sans / mono при близкой геометрии.

Подбор вдохновлён принципами сайтов colorscheme.ru, a1z.ru (статья о выборе
цвета), fontjoy.com, mixfont.com и fontbrief.com: сначала выбирается
  доминирующий нейтральный тон, затем один акцент и семантические цвета,
  после чего подбирается контрастная шрифтовая пара.

## Анимации

1. **Кнопки** — плавное изменение цвета при наведении, быстрая подсветка
   при нажатии и возврат в исходное состояние (`AnimatedButton`).
2. **Объекты** — рост полосы прогресса, движущийся индикатор активного раздела,
   появление панели администратора, всплывающие уведомления, анимация столбцов
   графика и перехода между экранами.
3. **Фон** — `AnimatedBackground` сам двигает мягкие градиентные пятна по синусоиде
   без участия пользователя; используется в окне входа и на главной странице.

## Отчёты и резервное копирование

Кнопки на странице «Прогресс» и в панели администратора формируют:

1. `habits_report_YYYY-MM-DD.csv` — выполнение привычек: дни истории, выполнено,
   процент, серия.
2. `goals_report_YYYY-MM-DD.csv` — прогресс целей с расчётом статуса
   («В работе» / «Почти готово» / «Завершено»).

CSV пишется в UTF-8 с BOM и разделителем `;`, поэтому сразу открывается в Excel
с корректной кириллицей. Резервная копия создаётся через `sqlite3.Connection.backup()`
в папку `backups/`.

## Git для защиты

Репозиторий: `https://github.com/egorloginov7/habit_tracker`. Ветки: `main`
и `feature/search-and-filters` (слита через `merge --no-ff`), также в истории
есть пара коммитов `Demo: add temporary note...` и `Revert "Demo: ..."` —
демонстрация отката.

```bash
# История коммитов
git log --oneline --graph --decorate --all

# Ветки и слияние
git branch -a
git checkout -b feature/search-and-filters
git commit -am "Add search and filters"
git checkout main
git merge --no-ff feature/search-and-filters

# Демонстрация отката
git revert <хэш_коммита>
```

В репозитории есть основная ветка `main`, ветка `feature/search-and-filters`
и коммит-демонстрация `revert`. Для защиты достаточно показать вывод команд выше
и объяснить, какой коммит откатывает `git revert`.
